# 周辺視フラッシュ暗算

画面の中央を凝視せず、周辺視で数式に気づいて暗算し、**声で答える**ための練習用ページ。
単一の HTML ファイルだけで動く。ビルド不要、外部ライブラリなし、通信なし。

公開先: https://u10g.github.io/voice-flash-anzan/

## 使い方

1. 上記 URL をスマートフォンまたは PC のブラウザで開く
2. 「設定 / 環境チェック」を開き、**音声認識を試す** と **マイクを試す** で使える方式を確認する
3. 「開始」を押し、マイクの使用を許可する
4. 出題されたら答えを声に出す。正解すると次の問題へ進む

### 解答方法

| 方式 | 必要な権限 | 内容 |
|---|---|---|
| 音声認識 | マイク | 常時聞き取り、答えの数値と一致したら正解。既定 |
| タップして発話 | マイク | 画面をタップした直後の 5 秒だけ聞き取る。常時聞き取りが不安定な端末向け |
| 発声検出 | マイク | 言葉は認識しない。声を出したことだけ検知して答えを表示し、自分で採点する |
| タップ入力 | なし | 数字キーで入力する。音声が一切使えない環境向け |

音声認識が使えない／途中で続かない場合は、発声検出またはタップ入力へ自動的に切り替わる。

## 動作環境

| 環境 | 音声認識 | 備考 |
|---|---|---|
| iOS / iPadOS Safari 14.5 以降 | ○ | ホーム画面に追加した状態（standalone）では動かない報告があるため、Safari で開く |
| iOS の Safari 以外（Chrome / Firefox / Edge） | × | Web Speech API が使えない。発声検出かタップ入力を使う |
| Android Chrome | ○ | 1 発話ごとに認識が終了するため自動で再接続する（`continuous` が効かない仕様） |
| PC の Chrome / Edge | ○ | |
| Firefox | × | 既定で無効 |
| アプリ内ブラウザ（LINE など） | △ | 使えないことが多い。Safari / Chrome で開く |

- **HTTPS が必須**。`http://` や `file://` では音声認識もマイクも動かない。
- 音声認識には**インターネット接続が必要**。

詳細な根拠は [docs/mobile-support.md](docs/mobile-support.md) を参照。

## プライバシーと注意事項

- **このページ自体は、通信も保存もしない。** 外部への送信（`fetch` / `XHR` / WebSocket）、外部 CDN、フォント、アナリティクスを一切使っていない。Cookie・localStorage も使わない。設定と成績はページを閉じると消える。
- ただし**音声認識中は、ブラウザが音声を Apple / Google の音声認識サーバへ送信する**。これは Web Speech API の仕様によるもので、ページ側からは制御できない。音声を外部へ出したくない場合は「発声検出」または「タップ入力」を使う。
- マイク以外の権限（カメラ・位置情報など）は要求しない。
- GitHub Pages で配信されるため、**訪問時の IP アドレスは GitHub に記録される**（[GitHub の記載](https://docs.github.com/en/pages/getting-started-with-github-pages/what-is-github-pages)）。
- 「フラッシュ」表示は数字が短い間隔で切り替わる。光刺激に弱い場合は使用しないこと。合図音・正誤音は端末の音量に従う。

## うまく動かないとき

| 症状 | 対処 |
|---|---|
| マイクのアイコンが点かない | ブラウザのサイト設定でマイクを許可する。iOS は 設定 → Safari → マイク を確認 |
| 「音声認識が使えない」と出る | アプリ内ブラウザ／ホーム画面起動の可能性。Safari または Chrome で URL を直接開く |
| 認識が途切れる | 正常な動作。自動で再接続する。それでも続かない場合は「タップして発話」に切り替える |
| 「ネットワークエラー」が続く | 音声認識はオンライン必須。機内モードや圏外を確認する |
| 数字を言っても反応しない | 「じゅうご」「15」のようにはっきり短く言う。診断パネルの「聞き取り結果」に何が認識されているか出る |

環境チェック欄の「診断をコピー」で、端末・ブラウザ・エラー内容をまとめて取得できる。

## 開発

単一ファイル構成のため、`index.html` を編集するだけでよい。ローカル確認は HTTP サーバー経由で行う（`file://` では API が動かない）。

```
python3 -m http.server 8000
# http://localhost:8000/ を開く（音声認識は https か localhost が必要）
```

`main` ブランチへの push で GitHub Actions が GitHub Pages へデプロイする（`.github/workflows/pages.yml`）。
実機での確認手順は [docs/TESTING.md](docs/TESTING.md) を参照。
